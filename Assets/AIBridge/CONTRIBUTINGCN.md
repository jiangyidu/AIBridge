# 贡献指南

AI Bridge 2.x 的发布架构是 Unity Editor-only 纯 C#，最低兼容 Unity 2018.4。

提交改动时请遵守：

- 不新增外部进程、本地监听服务或安装器依赖。
- 不使用 Unity 2018.4 之后才提供的 API，除非有条件编译和旧版本替代实现。
- Agent 长期状态必须可序列化到 `Library/AIBridge`；不要依赖静态字段、窗口实例或后台任务跨 Domain Reload 存活。
- 任何 Assets 写入都应在副作用前保存意图，并提供哈希冲突检测、超时和恢复路径。
- 可变更场景的工具应使用 Undo；文件/资产工具应限制路径并避免覆盖已有用户资产。
- 生成代码编译与执行必须分离，禁止弱化默认关闭的执行开关。
- 不持久化 API Key 或其他凭据。

验证至少包括：C# 编译、正常编译事务、错误源码回滚、Domain Reload 恢复、取消流程和危险源码拒绝。
