# 更新日志

## 2.0.0

- 改为 Unity Editor-only 纯 C# Agent，移除旧 Python 服务、pip 安装、端口发现、本地代理进程及其源码。
- 新增可跨 Domain Reload 恢复的磁盘状态机。
- 修复状态文件中的 `0` 被 LitJson 识别为 `Int32` 后无法恢复到 `Int64`，导致代码编译成功但 Agent 主循环在 Domain Reload 后中止的问题。
- 状态文件损坏时改为保留原文件、低频重试并在窗口中显示恢复错误，避免每帧重复解析和刷满 Editor.log。
- 新增有限 LLM 重试、普通工具不确定提交保护和最大步骤限制。
- 认证失败、余额不足和无效请求改为立即停止；仅对超时、429 和 5xx 有限重试。
- API Key 改用带版本标识的 AES 存储，启动前持久化以支持 Domain Reload；无法解密的旧密文不再发送。
- 新增生成源码两阶段事务、原文件备份、哈希冲突检测、完整编译周期错误累计和失败自动回滚。
- 编译成功后要求新脚本域验证目标类型/方法，编译不再隐式执行代码。
- 生成代码自动执行默认关闭，并加强危险源码检查。
- 自动初始化仅在 Unity 主 Editor 进程运行，资源导入 Worker 不再读取会话、扫描命令或推进编译事务。
- 活动会话中断超过 5 分钟后会安全停止，避免在项目状态已变化时自动重放旧操作。
- 命令执行仅允许带 `[AgentCommand]` 的 public static 方法；删除无调用的 1.x Server/端口/批处理/测试 API 和与桥接无关的通用 `GameUtility` 命令库。
- `AgentTools.json` 改为缓存并校验，删除面向模型的旧编译轮询工具，由宿主统一负责跨 Domain Reload 的编译事务轮询。
- 聊天内容显示时会替换不受字体支持的装饰符号，并移除控件中的 Emoji，避免每次重绘都产生缺字警告并持续放大 `Editor.log`。
- 对话栏新增可持久化的“锁定滚动”开关：未勾选时自动跟随最新内容，勾选后保留用户手动滚动位置。
- 操作窗口合并为单一的发送/终止按钮和命令执行入口，集成环境检查，命令分类按注册内容动态生成，并在 Agent 运行期间锁定会产生状态冲突的操作。
- 删除内置 LitJson 中无效的方法级 CLS 标记，消除该包源码引发的 `CS3021` 警告。
- 移除重复的独立环境向导，主窗口提供纯 C# 环境检查；最低兼容 Unity 2018.4。
- 菜单入口移动到 `Tools/AIBridge/AI Assistant`，并移除导入阶段在商品根目录外静默创建用户文件的行为。
- 命令注册表成功扫描默认不再写入 Console；需要诊断时可定义 `AIBRIDGE_VERBOSE_LOGS`。
